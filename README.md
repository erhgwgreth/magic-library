# 마법도서관에 불이 켜지면 — 1단계 (자원 카운터)

다른 앱에서 타이핑하면 **마법 잉크 / 고요한 촛불 / 교정 깃털** 숫자가 올라가는,
가장 작은 동작 검증용 버전입니다. 화면 꾸미기는 아직 없습니다.

## 실행 방법

1. [Node.js](https://nodejs.org) 설치 (LTS 버전 권장)
2. 이 폴더에서 터미널을 열고:

   ```bash
   npm install
   npm start
   ```

작은 창이 뜨면, **그 창은 클릭하지 말고** 메모장·코드 편집기 등 다른 앱에서
타이핑해 보세요. 숫자가 올라가면 성공입니다.

## 플랫폼별 권한 (중요)

- **macOS**: 처음 실행하면 키 입력이 안 잡힐 수 있습니다.
  `시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용(또는 입력 모니터링)`에서
  터미널(또는 Electron) 앱에 권한을 허용한 뒤 다시 실행하세요.
- **Windows**: 대개 바로 됩니다. 백신이 "키 입력 감지" 관련 경고를 줄 수 있는데,
  전역 키 후킹을 쓰는 앱이라 정상입니다.

## 지금 구조 한눈에

- `main.js` — 전역 키 입력을 받아 자원으로 환산 (게임의 핵심)
- `preload.js` — 메인 → 화면으로 데이터를 안전하게 전달
- `index.html` — 자원 숫자를 보여주는 임시 화면

## 자원 규칙 (현재 버전)

- **마법 잉크**: 게임 창이 떠 있지 않을 때(=작업 중) 친 글자 키 1개당 +1
- **교정 깃털**: Backspace / Delete 1번당 +1
- **고요한 촛불**: 게임 창 미포커스 + 최근 5초 내 작업 타이핑이 있으면 1초당 +1
  (5초까지의 짧은 멈춤은 집중 유지로 인정 = 잠깐 쉬는 시간 보상)

> 개인정보: 어떤 키였는지는 저장하지 않고 '횟수'만 셉니다.
> `main.js`에서 `e.keycode`는 Backspace/Delete 분류용으로만 잠깐 보고 버립니다.
